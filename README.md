## 📖 專案介紹

本專案旨在使用卷積神經網絡（CNN）模型來分類「Best Artworks of All Time」數據集中的藝術作品，並依據畫家的風格進行分類。數據集包含多個著名畫家的作品，目的是建立一個模型能夠辨識畫作的創作風格。

此專案要求在模型訓練過程中手動設計並堆疊 CNN 層，而不使用 Transfer Learning 或預訓練模型如 ResNet、Inception 等知名架構。我的目標是通過調整不同的網絡結構和參數，優化模型的分類效果。

## 類別不平衡處理方法

在本專案中，我嘗試了多種處理類別不平衡的方法，包括數據增強、過採樣與類別權重的調整。以下是每種方法的具體介紹：

### 1. **數據增強 (Data Augmentation)**

數據增強是一種常見的處理方法，通過隨機變換圖像（例如旋轉、翻轉、縮放等）來擴增訓練集的多樣性，從而提升模型的泛化能力。在本專案中，我根據不同條件嘗試了以下增強方式：

- **有條件增強：** 根據畫家作品數量較少的情況進行增強。這樣可以增加少數類別的樣本數量，防止過擬合。
- **無條件增強：** 在所有數據上進行隨機增強，不分畫家的作品數量。

然而，經過多次實驗後，我發現數據增強並未顯著提高模型的準確率，反而在某些情況下可能降低準確率，這可能是因為過度增強少數類別樣本會引入過多的噪音，影響模型學習的質量。

### 2. **過採樣 (Oversampling)**

過採樣是一種增強少數類別樣本數量的方法，在本專案中，我嘗試了以下兩種條件進行過採樣：

- **有條件過採樣：** 根據畫家作品數量較少的情況進行過採樣。具體來說，我針對畫家作品數量低於平均數的畫家進行過採樣，從而平衡各類別的樣本數量。
- **無條件過採樣：** 對所有畫家進行過採樣，無論其作品數量多寡。

我在試驗過後發現，無論使用作品數量還是標準差來作為條件進行過採樣，這些方法並未能有效提升模型的準確率，反而在某些情況下會導致模型性能的下降。過採樣可能導致模型過度擬合某些特定的樣本，從而對其他類別的區分能力降低。

### 3. **類別權重 (Class Weights)**

最終，我發現調整類別權重是最有效的處理類別不平衡的方法。類別權重的調整使得模型在訓練過程中對少數類別給予更高的重視，從而平衡了各類別對模型訓練的貢獻。經過實驗，類別權重的調整能夠顯著提高模型的準確率，相較於數據增強和過採樣，這是最有效的策略。

#### **類別權重計算**

在處理類別不平衡的情況下，我首先計算每個類別的權重，並將其應用到訓練過程中。為了避免對少數類別的過度擬合，我根據每個類別的樣本數量來設定權重。具體來說，權重越大表示該類別的樣本越少，模型在訓練過程中將更加關注這些樣本。

在程式中，我使用 `class_weights_dict` 來保存每個類別的權重。類別權重的計算方式通常為：
- 類別權重 = `總樣本數 / (類別樣本數 * 類別數量)`

例如，若某個類別的樣本數量較少，則該類別的權重會較大，模型在訓練過程中會對該類別賦予更多的關注。

### 結論

- 在處理類別不平衡問題時，**類別權重的調整**對提升準確率最有效。
- 嘗試過的**數據增強**和**過採樣**方法，無論是基於畫家作品數量的條件還是基於標準差的條件，都未能有效增加模型準確率，甚至可能導致準確率下降。

因此，最終的最佳策略是使用類別權重來解決類別不平衡問題，並放棄過度依賴數據增強和過採樣的方案。

## 早停 (EarlyStopping) 和學習率衰減 (ReduceLROnPlateau)

在本專案中，我使用了兩個常見的回調函數，**早停 (EarlyStopping)** 和 **學習率衰減 (ReduceLROnPlateau)**，來提升模型訓練過程的效率和效果，避免過擬合並加速訓練。

### 1. **EarlyStopping (早停)**

`EarlyStopping` 回調函數用來監控模型的驗證損失 (`val_loss`)，如果在指定的 **耐心值 (patience)** 內，模型的驗證損失沒有改善，則提前停止訓練，並恢復訓練過程中驗證損失最小的模型權重。這樣可以避免過度訓練並減少計算資源的浪費。

- **monitor**: 監控的指標，這裡設定為 `val_loss`，即驗證集的損失。
- **patience**: 如果 `val_loss` 在 5 個連續 epoch 內沒有改善，則停止訓練。
- **restore_best_weights**: 當停止訓練時，恢復訓練過程中最好的權重。
- **verbose**: 訓練過程中的輸出級別，設為 `1` 會顯示訓練過程中的相關訊息。

```python
early_stopping = EarlyStopping(
    monitor='val_loss',
    patience=5,
    restore_best_weights=True,
    verbose=1
)
```

### 2. ReduceLROnPlateau (學習率衰減)
ReduceLROnPlateau 回調函數根據驗證損失 (val_loss) 的改善情況動態調整學習率。如果在指定的耐心值內，驗證損失沒有改善，則會將學習率乘以一個預定的衰減因子，這有助於模型在訓練過程後期進行微調，避免學習過程中的震盪。

- monitor: 監控的指標，這裡設定為 val_loss。
- factor: 每次學習率衰減時，學習率將乘以該因子 (這裡設為 0.5，即學習率將減半)。
- patience: 如果在 3 個 epoch 內沒有改善，則會衰減學習率。
- min_lr: 學習率的最小值，防止學習率衰減過低。
- verbose: 訓練過程中的輸出級別，設為 1 會顯示學習率調整的相關訊息。

```python
reduce_lr = ReduceLROnPlateau(
    monitor='val_loss',
    factor=0.5,
    patience=3,
    min_lr=1e-6,
    verbose=1
)

```
這兩個回調函數的使用能夠有效提升訓練過程的效率，防止過擬合，並確保模型訓練過程中的學習率調整符合需求，進而提升最終的模型性能。

## 10折交叉驗證 (10-Fold Cross Validation)

在本專案中，我使用了 **10折交叉驗證** 來訓練和評估每一個模型的表現。10折交叉驗證是一種常用的驗證方法，可以幫助我更全面地了解模型的表現並避免過擬合。

### 1. **交叉驗證的過程**

10折交叉驗證將數據集分為 10 個子集。在每一次訓練過程中，選擇 9 個子集作為訓練數據，剩下的一個子集作為驗證數據。這個過程會重複 10 次，每次選擇不同的子集作為驗證數據。最終，通過將每次訓練結果的評估指標（例如 F1-score 或準確率）進行平均，來獲得模型的整體表現。

### 2. **找出最佳模型**

在訓練過程中，通過計算每個模型在每一折驗證集上的表現，我可以評估模型的穩定性和準確度。最終，根據每折的結果，選擇 **F1-score** 或準確率最高的模型作為最佳模型。這樣做的目的是確保選出的模型不會僅僅依賴於某一個驗證集，而是能夠在不同數據集上都有穩定的表現。

### 3. **交叉驗證的優點**

- **更穩定的性能評估**：相比於單次訓練和驗證，交叉驗證能夠減少因數據隨機劃分所帶來的偏差，提供更加穩定和可靠的模型評估。
- **充分利用數據**：在每一輪交叉驗證中，都會有不同的子集作為訓練和驗證數據，使得所有的數據都有機會被用來訓練和測試模型，從而更充分地利用了數據。
- **減少過擬合風險**：由於訓練和測試的數據集不同，交叉驗證有助於檢測模型是否存在過擬合現象。

### 4. **實現**

以下是實現10折交叉驗證的核心邏輯：

```python
from sklearn.model_selection import KFold

    # 創建 Dataset

    fold_model = create_model()
    fold_model.fit(fold_train_ds, validation_data=fold_val_ds, epochs=EPOCHS)

    # 計算 F1-score 或 Accuracy
    y_true = []
    y_pred = []

    for x_batch, y_batch in fold_val_ds:
        preds = fold_model.predict(x_batch)
        y_true.extend(tf.argmax(y_batch, axis=1).numpy())
        y_pred.extend(tf.argmax(preds, axis=1).numpy())

    score = f1_score(y_true, y_pred, average='macro')
    print(f"✅ Fold {fold + 1} F1-score: {score:.4f}")

    if score > best_score:

print(f"\n🌟 Best model F1-score: {best_score:.4f}")
```
 
## 多樣性模型後的模型權重與權重投票 (Weighted Voting)

在本專案中，為了進一步提高模型的性能，我採用了 **集成學習** 方法，並使用了 **權重投票** 的技術。集成學習的目的是將多個不同的模型結果進行結合，以獲得比單一模型更穩定和準確的預測結果。這種方法特別適用於模型表現不穩定或在不同數據集上表現不同的情況。

- **集成學習** (Ensemble Learning) 是指將多個模型的預測結果結合，進而提高最終預測準確度的技術。這是您的目標，並且我正通過加權投票來實現這個目標。

### 1. **投票方法**

我試驗了兩種投票方法，並根據驗證集的表現選擇了最適合的方案：

- **基於驗證集準確率的軟/硬投票**
  - **硬投票**：對每個模型的預測結果進行投票，選擇最多的預測類別作為最終預測結果。
  - **軟投票**：根據每個模型的預測機率，對每個類別的預測機率進行加權平均，並選擇最大概率的類別作為最終預測結果。
  
- **基於F1-score的投票**
  - 除了使用驗證集的準確率外，我還測試了基於每個模型在驗證集上的 **F1-score** 來進行加權投票。每個模型的 F1-score 會作為該模型的權重，然後將這些權重加權的預測結果進行投票。

為了根據每個模型的表現來調整最終投票的權重，我首先對每個模型的驗證集表現進行評估。具體來說，我計算每個模型在驗證集上的準確率或 F1 分數，並將其作為該模型的權重。權重越大，表示該模型的表現越好，在最終投票中所佔的權重也越大。

```python
# 計算每個模型的權重
model_weights = {
    model_idx: best_val_accuracy  # 用於更新模型權重的指標，例如驗證集準確率
    for model_idx, best_val_accuracy in model_accuracies.items()
}
```

在進行模型預測時，使用加權投票方法來計算每個類別的最終預測結果。具體來說，對於每一個測試樣本，將所有模型的預測結果加權平均，權重由每個模型的表現決定。最終選擇預測概率最高的類別作為該樣本的預測結果。

```python
# 進行加權投票
def weighted_vote(preds_list, model_weights):
    # preds_list 是所有模型對每個樣本的預測結果，每個預測結果是類別的機率分布
    weighted_preds = np.zeros_like(preds_list[0])  # 初始化為與單一預測結果相同的形狀

    # 根據每個模型的權重加權預測結果
    for i, preds in enumerate(preds_list):
        weighted_preds += model_weights[i] * preds

    # 返回加權預測結果中機率最大的類別
    return np.argmax(weighted_preds, axis=-1)
```
這樣，在進行最終的預測時，每個模型的預測結果會根據其權重進行加權，從而更好地反映出每個模型的貢獻。

### 2. **實現細節**

根據您的程式碼，權重投票的過程如下：

- 每個模型在驗證集上的預測結果（無論是硬投票還是軟投票）都會被收集並進行加權。權重是根據每個模型在驗證集上的 **F1-score** 或 **val_accuracy** 指標動態設定的。
- 在進行集成預測時，會使用加權的投票方式，根據每個模型在驗證集上的表現，對各個類別的預測結果進行加權並投票，最終選擇預測概率最大的類別作為最終預測結果。

### 3. **集成模型的效果**

在實驗中，我發現基於驗證集的準確率和F1-score進行加權投票，能夠顯著提升模型對測試集的預測準確率。通過這種方式，我將每個模型的優勢集中起來，避免了單一模型可能出現的偏差或過擬合問題。

這種 **權重投票** 方法實際上是集成學習的一種實現方式。集成學習的基本思想是結合多個基礎模型的預測結果，以達到更穩定且更準確的預測。最終，我的 **集成模型** 以權重投票的方式將多個模型的預測結果結合在一起，這大大提升了測試集的準確性。

### 4. **效果比較**

我試驗了不同的投票策略，最終發現，**根據F1-score來加權投票** 的方法最能提升模型對測試集的準確率。這說明在處理類別不平衡問題時，F1-score作為權重可以有效提升模型的整體表現，尤其是在某些類別數量較少時。

### 5. **實現代碼**

```python
# 假設我有多個模型
models = [model_0, model_1, model_2, model_3, ...]

# 基於模型的F1-score進行加權投票
model_weights = [f1_score_0, f1_score_1, f1_score_2, f1_score_3, ...]
model_preds = [model.predict(x_test) for model in models]

# 計算加權預測
weighted_preds = np.average(model_preds, axis=0, weights=model_weights)

# 選擇加權後預測概率最大的類別
final_preds = np.argmax(weighted_preds, axis=1)
```

### 6. 結論
最終，我選擇了基於 F1-score 來進行權重投票的方法，這能夠有效提高模型在測試集上的準確率。這種集成方法成功地將多個模型的優勢結合，並顯示出相較於單一模型更為穩定和可靠的表現。


## 技術難題與最終成果

在進行本專案的過程中，我遇到了幾個主要的技術難題，並進行了一些嘗試與優化。最終，我成功將模型的準確率提升至 **42.8%**，並且達到了預期的結果。

### 1. 類別不平衡處理

由於數據集存在顯著的類別不平衡問題，我最初嘗試使用 **SMOTE (Synthetic Minority Over-sampling Technique)** 來處理不平衡問題。該方法能夠生成合成的少數類別樣本，理論上有助於提高模型對少數類別的識別能力。然而，由於 **SMOTE** 方法非常耗時且難以有效優化，因此我最終放棄了此方法，並探索了其他方式來處理類別不平衡。

### 2. 數據增強與過採樣

我對數據增強和過採樣進行了多種嘗試，並根據不同條件進行調整（例如：畫家作品數小於平均值或根據標準差進行條件判斷），卻反而會大幅降低準確率。儘管如此，我的實驗結果顯示，無論是否進行這些處理，我的模型結構仍然能夠在測試集上取得相對較高的準確度。這表明即使在類別不平衡的情況下，適當的模型結構也能有效達到較好的表現，因此我最終決定保持目前的數據處理方法。

### 3. 集成學習與GPU記憶體限制

在進行 **集成學習 (Ensemble Learning)** 時，我面臨了 **GPU 記憶體不足** 的問題，特別是在同時訓練多個模型時。為了避免這個問題，我在程式碼中加入了許多垃圾回收（GC）機制，以釋放記憶體。然而，這樣的措施仍然無法完全消除 GPU 記憶體的壓力。最終，我選擇了排除那些 F1 分數非常低的模型，並進行模型選擇，而不是一次性訓練所有 10 種模型。這樣能夠有效減少記憶體佔用，同時提升集成模型的表現。
